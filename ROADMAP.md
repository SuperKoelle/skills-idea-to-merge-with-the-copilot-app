# Mona's Bookmark Manager Roadmap

A clear path to making saved bookmarks easier to organize, manage, and protect.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Organization | Search & filter bookmarks | 🚀 | High |
| Management | Edit a saved bookmark | 🚀 | High |
| Organization | Add tags or folders | 🚀 | Medium |
| Portability | Import and export bookmarks | 🚀 | Medium |
| Reliability | Prevent duplicate slugs on re-add | 🐞 | Medium |
| Validation | Require a valid, non-empty URL | 🐞 | High |
| Data safety | Protect bookmarks from localStorage loss | 🐞 | Medium |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a saved bookmark — priority: high
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs can be created when a bookmark is re-added — priority: medium
- ⚠️ Empty or invalid URLs may be accepted — priority: high
- 💾 Bookmarks can be lost if browser localStorage is cleared — priority: medium
